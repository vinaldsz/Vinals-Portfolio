# Vinal's Portfolio

A modern, responsive portfolio website showcasing my work as a Data Engineer and Software Developer.

## Live Demo

**URL**: [Portfolio Website](https://vinals-portfolio.vercel.app/)

## About

This portfolio showcases my professional projects across:

- **Data Engineering**: Data pipelines, lakehouses, and ETL systems
- **AI/ML**: Machine learning models and RAG applications
- **DevOps & Cloud**: Microservices, CI/CD, and distributed systems

## Tech Stack

This project is built with:

- **Vite** - Fast build tool and dev server
- **TypeScript** - Type-safe JavaScript
- **React** - UI framework
- **vite-react-ssg** - Static-site generation / prerendering
- **Tailwind CSS** - Utility-first CSS framework
- **Radix UI** - Unstyled, accessible primitives (`Select`, `Label`) where native HTML isn't enough
- **oxlint** - Linting

## Local Development

### Prerequisites

- Node.js & npm installed - [install with nvm] (https://github.com/nvm-sh/nvm#installing-and-updating)

### Setup

```sh
# Clone the repository
git clone https://github.com/vinaldsz/Vinals-Portfolio.git

# Navigate to the project directory
cd Vinals-Portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

The site will be available at `http://localhost:5173`

## 📦 Build

```sh
# Create production build
npm run build

# Preview production build
npm run preview
```
